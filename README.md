# wave-ball-reducer

鋼球式サイクロイド減速機 (ボールリデューサ) の 3D モデルです。Python の CAD ライブラリ [build123d](https://github.com/gumyr/build123d) を使い、寸法をパラメータで変えられるように作っています。FDM 方式 (樹脂を溶かして積層する方式) の 3D プリンタで印刷して試作することを目的としています。

設計の根拠にした論文は次のとおりです。

> Juanjuan WANG, Xueliang PING, "The Design Method of Hypocycloid and Epicycloid of Ball-type Speed Reducer," *International Research Journal of Advanced Engineering and Science*, Vol. 4, Issue 2, pp. 185–187, 2019.

論文の PDF は再配布を避けるため、このリポジトリには含めていません (`.gitignore` で除外)。手元では `literature/papers/` に置いています。

## 動作原理

向かい合う 2 枚の円板に波形の溝を彫り、そのあいだに鋼球を挟みます。

- **内サイクロイド円板** (部品 6) には、波が nb+1 個ある溝 (内サイクロイド溝) を彫ります。nb は鋼球の数です。
- **外サイクロイド円板** (部品 8) には、波が nb−1 個ある溝 (外サイクロイド溝) を彫ります。
- 入力軸の偏心カムが円板 6 を偏心量 A で公転させます。円板 6 の自転はオルダム継手 (自転を止め、平行移動だけを許す継手) で止めます。
- 鋼球は 2 本の溝が交わる点に入っているので、円板 6 が公転すると円板 8 が回ります。円板 8 が出力です。

減速比は i = −(nb−1)/2 です (負号は、出力が入力と逆向きに回ることを示します)。既定値 nb=21 では減速比は 10 になります。

## 論文から変えた点と、独自に判断した点

- **減速比**: 論文は「鋼球の数は減速比から決める」と書くだけで、減速比の式は示していません。外サイクロイドの波数 nb−1 がそのまま減速比になると読みがちですが、円板 6 が自転せず円板 8 が出力するときの運動学を数値で検証すると、減速比は (nb−1)/2 でした。検証では、入力 1 回転のあいだ溝の交点 (鋼球が入る位置) が消えずに保たれる条件を調べました。この結果はテスト `test_ratio_is_half_of_epicycloid_waves` で確かめています。
- **K の定義**: 論文の式 (5) の K = A/r0 を採用しました。A は偏心量、r0 は転がり円の半径 (= Rb/nb) です。Table II にある K = A·nb/(2Rb) は係数 2 が式 (5) と矛盾するため、誤植とみなしました。
- **溝の山の削れ (アンダーカット) を避ける**: 論文の推奨値 (K は 0.42〜0.63、K2 は 1.0〜1.15) では、溝中心線の曲率半径が鋼球の溝半径より小さくなり、溝の山が削れます。K2 は Rb·sin(π/nb)/rb で定義される、鋼球の間隔を決める係数です。そこで鋼球の間隔を広げて、K と K2 を推奨範囲の外にしました。値は関数 `search_K_K2` で決めます。この関数は次の 2 条件を満たす組み合わせのうち、外径が最小になる K と K2 を探します。
  - 偏心量 A ≥ 0.6mm (FDM の誤差 0.1〜0.2mm より十分大きくする)
  - 最小曲率半径 ≥ 1.1 × 溝半径
- **運動伝達部**: 論文の「平行四辺形機構」は記述が粗いため、鋼球式のオルダム継手として設計しました。円板 6 と 5 のあいだに X 方向の直溝、円板 5 とエンドカバー 3 のあいだに Y 方向の直溝を設け、それぞれに鋼球を 4 個ずつ入れます。
- **溝の断面**: 論文と同じく 2 つの円弧からなる「ゴシックアーチ」形にしました。溝の深さは論文の式 (10) の h = rb(1 − sinβ) です。
- **出力円板の支持**: 出力円板 8 の上面の円筒部 (半径 20mm) をふた 11 の中央穴に通し、すべり軸受にしました。円板 8 が浮き上がる動きは、ふた下面の細い環状の突起で受けます。
- **ねじの受け**: ハウジング 10 に正六角形の止まり穴 (内接円の直径 3.0mm) を開け、M3 ねじを角に食い込ませて固定します。ナットは使いません。ねじの長さは、手持ちの M3×6 / 8 / 12 / 16 の中から「通す側の板厚 + かかり 6mm」以上で最短のものを自動で選びます。

## 既定パラメータと主要寸法

パラメータはすべて `reducer.py` の dataclass `Params` に集約しています。下表の派生量は、パラメータから計算した値です。

| 量 | 値 |
|---|---|
| 鋼球半径 rb | 3.0mm (φ6) |
| 減速用鋼球の数 nb | 21 (外サイクロイドの波数 20、内サイクロイドの波数 22) |
| 減速比 | −10 |
| K / K2 | 0.28 / 2.24 |
| 鋼球ピッチ円半径 Rb | 45.09mm |
| 転がり円の半径 r0 | 2.147mm |
| 偏心量 A | 0.601mm |
| 溝中心線の最小曲率半径 | 3.397mm (溝半径 3.05mm の 1.11 倍) |
| β (溝深さを決める角度) | 32° |
| 溝深さ h / 実際に削る最大深さ | 1.41mm / 1.50mm |
| 溝底の肉 groove_floor | 3.0mm |
| 板厚 (エンドカバー 3 / 中央円板 5 / 円板 6 / 出力円板 8 / ふた 11) | 4.49 / 5.99 / 5.99 / 4.49 / 4.0mm |
| 保持器の厚さ | 3.08mm |
| 胴の外径 / ねじ用の耳を含む最大寸法 | 116.7mm / 121.0mm |
| 全高 (入力軸の下端から出力面まで) | 52.6mm |
| 軸受 | 608ZZ (内径 8 × 外径 22 × 幅 7mm) × 2 |
| ねじ | M3×12 × 8 本 (エンドカバー側 4 本、ふた側 4 本) |

公差の既定値は次のとおりで、いずれも片側の値です。
- 鋼球と溝のすきま ball_clr: 0.05mm
- 軸受のはめあい fit_clr: 0.05mm
- 摺動部のすきま slide_clr: 0.05mm
- ふた穴と出力円筒部の半径方向のすきま lid_bore_clr: 0.05mm
- ふた突起と出力円板の軸方向のすきま lid_axial_clr: 0.05mm

最小肉厚 min_wall は 1.2mm です。

## 使い方

[pixi](https://pixi.sh) (パッケージ管理・タスク実行ツール) を使います。

```bash
pixi install      # 環境を作る (Python 3.12, build123d, numpy, pytest, ruff)
pixi run build    # out/ にモデルを書き出す。設計チェックの警告も表示する
pixi run test     # pytest を実行する (3 分ほどかかる)
pixi run view     # http://127.0.0.1:8765 でビューワーを配信する
```

ビューワーは次の URL で開きます。

- `http://127.0.0.1:8765/viewer.html`: 印刷する部品を、印刷時の向きで並べて表示する
- `http://127.0.0.1:8765/viewer.html?assembled`: 組み立てた状態で表示する

パラメータを変えるには、`reducer.py` の `Params` の既定値を書き換えるか、Python から次のように呼びます。

```python
from pathlib import Path
from reducer import Params, build, design_warnings, thin_walls

p = Params(nb=15, K2=2.6)
print(design_warnings(p), thin_walls(p))  # 削れ、偏心量、論文推奨範囲、肉厚のチェック
build(p, Path("out"))
```

## 出力ファイル

- `out/<部品>.step`: 全部品の STEP (購入品を含む)
- `out/<部品>.stl`: 印刷する 8 部品の STL。印刷時の向き (平らな面を z=0 に置く) で出力する。入力軸 1、エンドカバー 3、ふた 11 は裏返して置く
- `out/assembly.step`: 組立状態の STEP
- `out/assembled/<部品>.stl`: 組立位置のままの STL (購入品を含む 12 ファイル)。ビューワーの組立表示で使う

## テストで確かめていること

- 減速比 (溝の交点が保たれる条件)
- `Params` の既定値と `search_K_K2` の探索結果が一致すること
- 入力 1 回転を 12 姿勢に分けた各姿勢で、次の 3 点
  - 減速用鋼球を除く全部品のどの組み合わせでも干渉体積がゼロ
  - 減速用鋼球が両方の溝に収まる (溝面との距離が設定すきまどおり)
  - ふたと出力円板のすきまが設定どおり
- 最小肉厚、アンダーカットがないこと、造形範囲 220mm に収まること
- 書き出したファイルを読み戻せること
- 別の nb でも作り直せること

## 既知の懸念・未検証事項

- 実機で印刷して回したことはありません。検証は形状の幾何計算だけです。
- 公差の値はユーザーのプリンタの精度に合わせ、すべて片側 0.05mm (直径で 0.1mm) にしています。別のプリンタでは試し刷りで調整してください。
- 出力円板 8 は、印刷部品どうしのすべり軸受 (ふたの穴と突起) で支えています。摩擦と摩耗は未確認です。
- 入力軸が上へ抜ける動きは、軸のつばが出力円板の下面に当たって止めます。ここも擦れる可能性があります。
- 偏心カム軸受の外輪は、圧入と円板 6 上面の縁だけで保持しています。下方向の抜け止めはありません。
- 六角穴へのねじ込み (ナットなし) の保持力は未確認です。
- 円板 5、6、8 の下面の溝は、印刷時にオーバーハング (支えのない張り出し) になります。
- K と K2 は論文の推奨範囲の外にあり、ビルド時に警告が出ます (意図した設定です)。
