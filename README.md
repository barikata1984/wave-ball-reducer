# wave-ball-reducer

鋼球式サイクロイド減速機 (ボールリデューサ) の 3D モデルです。Python の CAD ライブラリ [build123d](https://github.com/gumyr/build123d) を使い、寸法をパラメータで変えられるように作っています。FDM 方式 (樹脂を溶かして積層する方式) の 3D プリンタで印刷して試作することを目的としています。

設計の根拠にした論文は次のとおりです。

> Juanjuan WANG, Xueliang PING, "The Design Method of Hypocycloid and Epicycloid of Ball-type Speed Reducer," *International Research Journal of Advanced Engineering and Science*, Vol. 4, Issue 2, pp. 185–187, 2019.

論文の PDF は再配布を避けるため、このリポジトリには含めていません (`.gitignore` で除外)。手元では `literature/papers/` に置いています。

## 動作原理

向かい合う 2 枚の円板に波形の溝を彫り、そのあいだに鋼球を挟みます。

- **内サイクロイド円板** (部品 6) には、波が nb+1 個ある溝 (内サイクロイド溝) を彫ります。nb は鋼球の数です。
- **外サイクロイド円板** (部品 8) には、波が nb−1 個ある溝 (外サイクロイド溝) を彫ります。
- 入力軸の偏心カムが円板 6 を偏心量 A で公転させます。円板 6 の自転はオルダム継手 (自転を止め、平行移動だけを許す継手) で止めます。
- 鋼球は 2 本の溝が交わる点に入っているので、円板 6 が公転すると円板 8 が回ります。円板 8 が出力です。

減速比は i = −(nb−1)/2 です (負号は、出力が入力と逆向きに回ることを示します)。既定値 nb=21 では減速比は 10 になります。

## 論文から変えた点と、独自に判断した点

- **減速比**: 論文は「鋼球の数は減速比から決める」と書くだけで、減速比の式は示していません。外サイクロイドの波数 nb−1 がそのまま減速比になると読みがちですが、円板 6 が自転せず円板 8 が出力するときの運動学を数値で検証すると、減速比は (nb−1)/2 でした。検証では、入力 1 回転のあいだ溝の交点 (鋼球が入る位置) が消えずに保たれる条件を調べました。この結果はテスト `test_ratio_is_half_of_epicycloid_waves` で確かめています。
- **K の定義**: 論文の式 (5) の K = A/r0 を採用しました。A は偏心量、r0 は転がり円の半径 (= Rb/nb) です。Table II にある K = A·nb/(2Rb) は係数 2 が式 (5) と矛盾するため、誤植とみなしました。
- **溝の山の削れ (アンダーカット) を避ける**: 論文の推奨値 (K は 0.42〜0.63、K2 は 1.0〜1.15) では、溝中心線の曲率半径が溝の半幅より小さくなり、曲がりの内側で溝が自分自身と重なって溝の山 (溝の脇の肉) が削れます。K2 は Rb·sin(π/nb)/rb で定義される、鋼球の間隔を決める係数です。そこで鋼球の間隔を広げて、K と K2 を推奨範囲の外にしました。値は関数 `search_K_K2` で決めます。この関数は次の 2 条件を満たす組み合わせのうち、外径が最小になる K と K2 を探します。
  - 偏心量 A ≥ 0.6mm (FDM の誤差 0.1〜0.2mm より十分大きくする)
  - 最小曲率半径 ≥ 1.1 × 円板面の高さでの溝の半幅 (`face_half_width`)

  鋼球中心は円板面より rb·sinβ = 1.59mm 上にあり、溝は面より下にしかありません。そのため、自己交差を決めるのは溝断面の半径 3.05mm ではなく、面の高さでの半幅 2.61mm です。鋼球が溝に触れる点 (中心線から 2.16mm) は、この半幅より内側にあります。以前は「曲率半径 > 1.1 × 溝断面の半径」で判定しており、この判定は厳しすぎました。検証の経緯は `notes/debug/2026-11-10_undercut-criterion.md` にあります。
- **運動伝達部**: 論文の「平行四辺形機構」は記述が粗いため、鋼球式のオルダム継手として設計しました。円板 6 と 5 のあいだに X 方向の直溝、円板 5 とエンドカバー 3 のあいだに Y 方向の直溝を設け、それぞれに鋼球を 4 個ずつ入れます。
- **溝の断面**: 論文と同じく 2 つの円弧からなる「ゴシックアーチ」形にしました。溝の深さは論文の式 (10) の h = rb(1 − sinβ) です。
- **出力円板の支持**: 出力円板 8 の上面の円筒部 (半径 20mm) をふた 11 の中央穴に通し、すべり軸受にしました。円板 8 が浮き上がる動きは、ふた下面の細い環状の突起で受けます。
- **ねじの受け**: ハウジング 10 に正六角形の止まり穴 (内接円の直径 3.0mm) を開け、M3 ねじを角に食い込ませて固定します。ナットは使いません。ねじの長さは、手持ちの M3×6 / 8 / 12 / 16 の中から「通す側の板厚 + かかり 6mm」以上で最短のものを自動で選びます。

## 使い方

[pixi](https://pixi.sh) (パッケージ管理・タスク実行ツール) を使います。

```bash
pixi install      # 環境を作る (Python 3.12, build123d, numpy, pytest, ruff)
pixi run build    # out/ にモデルを書き出す。設計チェックの警告も表示する
pixi run test     # pytest を実行する (3 分ほどかかる)
pixi run view     # http://127.0.0.1:8765 でビューワーを配信する
```

ビューワーは次の URL で開きます。

- `http://127.0.0.1:8765/viewer.html`: 印刷する部品を、印刷時の向きで並べて表示する
- `http://127.0.0.1:8765/viewer.html?assembled`: 組み立てた状態で表示する

パラメータを変えるには、`reducer.py` の `Params` の既定値を書き換えるか、Python から次のように呼びます。

```python
from pathlib import Path
from reducer import Params, build, design_warnings, thin_walls

p = Params(nb=15, K2=2.6)
print(design_warnings(p), thin_walls(p))  # 削れ、偏心量、論文推奨範囲、肉厚のチェック
build(p, Path("out"))
```

## 出力ファイル

- `out/<部品>.step`: 全部品の STEP (購入品を含む)
- `out/<部品>.stl`: 印刷する 8 部品の STL。印刷時の向き (平らな面を z=0 に置く) で出力する。入力軸 1、エンドカバー 3、ふた 11 は裏返して置く
- `out/assembly.step`: 組立状態の STEP
- `out/assembled/<部品>.stl`: 組立位置のままの STL (購入品を含む 12 ファイル)。ビューワーの組立表示で使う

## テストで確かめていること

- 減速比 (溝の交点が保たれる条件)
- `Params` の既定値と `search_K_K2` の探索結果が一致すること
- 入力 1 回転を 12 姿勢に分けた各姿勢で、次の 3 点
  - 減速用鋼球を除く全部品のどの組み合わせでも干渉体積がゼロ
  - 減速用鋼球が両方の溝に収まる (溝面との距離が設定すきまどおり)
  - ふたと出力円板のすきまが設定どおり
- 最小肉厚、アンダーカットがないこと、造形範囲 220mm に収まること
- 書き出したファイルを読み戻せること
- 別の nb でも作り直せること

## 既知の懸念・未検証事項

- 実機で印刷して回したことはありません。検証は形状の幾何計算だけです。
- 公差の値はユーザーのプリンタの精度に合わせ、すべて片側 0.05mm (直径で 0.1mm) にしています。別のプリンタでは試し刷りで調整してください。
- 出力円板 8 は、印刷部品どうしのすべり軸受 (ふたの穴と突起) で支えています。摩擦と摩耗は未確認です。
- 入力軸が上へ抜ける動きは、軸のつばが出力円板の下面に当たって止めます。ここも擦れる可能性があります。
- 偏心カム軸受の外輪は、圧入と円板 6 上面の縁だけで保持しています。下方向の抜け止めはありません。
- 六角穴へのねじ込み (ナットなし) の保持力は未確認です。
- 円板 5、6、8 の下面の溝は、印刷時にオーバーハング (支えのない張り出し) になります。
- K と K2 は論文の推奨範囲の外にあり、ビルド時に警告が出ます (意図した設定です)。

## 遊星減速機 (GM5208-24 用)

`planetary.py` は、ジンバル用アウターロータ BLDC の iFlight GM5208-24 を QDD (低減速比で出力側から逆駆動できるアクチュエータ) にするための、1 段遊星歯車減速機 (やまば歯) のパラメトリックモデルです。内歯車をハウジングと一体で固定し、太陽歯車を入力、遊星キャリアを出力にします。モーターと同軸に積みます。設計根拠は `literature/surveys/2026-11-10_planetary-qdd-design-basis.md` にまとめてあります (ページは PDF のページ)。

```bash
pixi run build-planetary   # out_planetary/ に STEP/STL/parts.json を書き出し、寸法・強度・警告を表示
```

ビューワーは `viewer.html?model=planetary` (印刷向き) と `viewer.html?model=planetary&assembled` (組立状態) で開きます。

### 構成と組立順序

z = 0 はモーターのロータ上面です。下から順に次の部品が並びます。

| 部品 | 区分 | 役割 |
|---|---|---|
| housing | 印刷 | 底板 (ステータに下からねじ止め) + モーターを囲む筒 + 内歯車の下半分 |
| motor GM5208-24 | 購入 | 外径 60.0 (実測 59.3 を包む値)、高さ 23.25 (実測 23.2〜23.3。公式値 31.2 とは異なる) の円筒で簡易モデル化。中空軸 (外径 15) を含む |
| sun_adapter | 印刷 | ロータ上面にねじ止めする板。上に六角ボス (二面幅 7) |
| sun | 印刷 | 太陽歯車。下面の六角穴がアダプタのボスに軸方向に滑り込む (浮動太陽) |
| planet_0..2 | 印刷 | 遊星歯車。中に 608ZZ を圧入 |
| 608ZZ × 3 | 購入 | 遊星の軸受 |
| carrier_output | 印刷 | 出力キャリア。片持ちの軸 (φ7.9) を 608 内輪に通す。上部の円筒 (ハブ) が出力面 |
| ring_lid | 印刷 | 内歯車の上半分 + ふた。ふたの穴がハブのすべり軸受になる |

やまば歯どうしは軸方向に差し込めません。このため、内歯車をやまばの頂点 (歯幅の中央) で上下に分け、太陽歯車をモーターから外せる浮動式にしました。組立順序は次のとおりです。

1. モーターをハウジングに入れ、底板の下からステータをねじ止めする。
2. sun_adapter をロータ上面にねじ止めする。
3. 遊星 3 個 (軸受を圧入済み) をキャリアの軸に通し、その間に太陽歯車を横から入れる (やまば歯は半径方向なら噛み合わせられる)。
4. この組 (太陽 + 遊星 + キャリア) を一体でハウジングに下ろす。遊星の下半分は内歯車の下半分にねじ込むように入り、組全体が少し回る。太陽の六角穴がアダプタのボスに入るよう、ロータを手で回して合わせる。
5. ring_lid を上から下ろす。内歯車の上半分が遊星の上半分にねじ込むように入る。M3 ねじで固定する。

この順序は形状から推論したもので、組立動作のシミュレーションはしていません。

### 採用した式と出典

- 歯数条件: 同心 Zr = Zs + 2Zp、組立 (Zs + Zr)/N が整数、隣接 Zp + 2 < (Zs + Zp)·sin(180°/N)。KHK 内歯車カタログ (Khk2025) p3。
- 減速比: 1 + Zr/Zs。Singh2025_COMPAct p2 式 (2)。
- 内歯車の干渉: KHK カタログ p2 の表 (歯数 60 の内歯車に噛む小歯車は 21〜43 歯)。KHK Gear Technical Reference「Calculation of Gear Dimensions」(Web、ページなし) の表 4.6 の条件 (標準 20° 内歯車で z2 > 34、z2 − z1 > 9) も `design_warnings` で確かめる。
- 転位: 同ページの表 4.3。x1 + x2 = 0 なら中心距離は標準のまま (αw = α)。同ページは z1 = 12 の歯車を正転位で切り下げから守る例を示す。切り下げを避ける条件 x ≥ 1 − z·sin²α/2 は教科書式で、KHK の該当 PDF は入手できず照合していない。太陽 xs = +0.3、遊星 xp = −0.3、内歯車 xr = xp。内歯車の歯先は ha2 = (1 − x2)m (同ページ表 4.6)。
- はすば: 同ページの表 4.9/4.11。本モデルは正面モジュールと正面圧力角で歯形を作り、断面を高さに比例して回す (ねじれ)。
- ねじれ角 20°: 直接の記載がある文献はない。Nguyen2025 p4 表 2 で、同じ中心距離 50mm の平歯 50 歯に対してはすば・やまば歯は 47 歯 (m = 1) なので、cosβ = 47/50 から β ≈ 19.9° と逆算した (他のモジュールでは 18〜23°)。KHK カタログ p4 の最大ねじれ角は 27°。
- 強度: 修正 Lewis 式 σ = Ft/(b·y·Kv·P)。Singh2025_ExternalInternalPlanetary p3 式 (9)。y = 0.154 − 0.912/z と Kv = 6.1/(6.1 + V) は教科書の形で、論文の参照先 [22] は未入手。Ft は 3 個の遊星で均等に分担すると仮定し、歯幅は全幅、ねじれによる強度の割増しはしない。
- 許容曲げ応力 10 MPa: 仮の値で、材料の強度表からは決められない。射出成形 PA6 でも、歯車試験で得た許容値は VDI 2736 の規格値の 38〜72% だった (Pogacnik2015 p10 表 7)。印刷遊星の試験では、カタログ強度の高い材料が先に割れた (Yoshida2023 p4–5)。破壊試験で決めること。
- バックラッシ: 各歯面を法線方向に flank_clr = 0.05mm 下げる (歯厚を減らす)。1 噛み合いあたりの法線方向のすきまは 0.1mm。値は鋼球式の公差 (片側 0.05mm) に合わせた仮定である。参考として Pogacnik2015 p5 表 1 は、熱膨張を見込んで中心距離を +0.05mm (m = 1) 広げている。遊星の中心距離を広げる center_clr も用意したが、太陽側のすきまは増え、内歯車側のすきまは減るので既定値は 0 にした。

### 減速比と大きさの選び方

`pixi run build-planetary` は、内歯車のピッチ円直径を 72mm にそろえた 3 案を比べて表示します。

| 歯数 Zs/Zp/Zr | m | 減速比 | 外径 | 太陽歯元応力 (0.4 N·m) | 遊星の歯底と 608 の間の肉 | 反映慣性の倍率 (減速比²) |
|---|---|---|---|---|---|---|
| 12/24/60 | 1.20 | 6 | 88.62 | 5.90 MPa | 1.49 | 36 |
| 12/30/72 | 1.00 | 7 | 88.24 | 8.34 MPa | 2.40 | 49 |
| 12/36/84 | 0.86 | 8 | 87.96 | 11.20 MPa | 3.05 | 64 |

12/24/60 (6:1、m = 1.2、遊星 3 個) を選びました。外径がほぼ同じなら、モジュールが大きいほど歯が太く、0.4mm ノズルでも形が出やすく、歯元応力も小さくなります。8:1 は短時間トルク 0.4 N·m で仮の許容値 10 MPa を超えます。減速比が小さいほど、出力側から見たロータ慣性 (減速比の 2 乗に比例) と逆駆動の抵抗が小さくなります。m = 1.2 は、24 歯の遊星に 608ZZ を収めて最小肉厚 1.2mm を守れる最小のモジュールです (m = 1.1 では肉厚 0.45mm に減る)。参考事例として、Mini Cheetah は 1 段遊星 6:1 (Katz2019 p3)、Yoshida2023 は印刷 1 段遊星 8:1 (9/27/63 歯、m = 1.5、20 N·m 以下で効率 80% 超、p1–3) です。Yoshida はやまば歯ではなくはすば歯から平歯に変えており、理由は軸方向力でした。本モデルはやまば歯なので、軸方向力は左右で打ち消し合います。

### 軸受とねじ

- 608ZZ は 3 個を遊星に使います。手持ち 5 個のうち 2 個は余ります。遊星は内歯車の上下半分に挟まれて軸方向の位置が決まるので、軸受は半径方向の荷重だけを受けます。
- 出力キャリアは、ハブとふたの穴のすべり軸受と、3 個の遊星で支えます。ハブは円板へ 45° の円すいで広がり、ふたの穴にも平行な 45° の円すい面があります。すきまは円筒部も円すい部も面に垂直に 0.05mm (lid_bore_clr) です。浮き上がりはこの円すい面で止まります (軸方向のあそび 0.07mm)。出力面を下にして刷るとき、円すいは 45° なのでサポートが要りません。
- ねじ: ring_lid → ハウジング M3×16 × 4 (ハウジング側は内接円 3.0mm の六角穴にねじ込み)、アダプタ → ロータ M3×6 × 4、底板 → ステータ M3×6 × 4。モーター側のねじは、モーターのねじ穴に入る深さが rotor_thread_depth / stator_thread_depth (既定 2.7mm、寸法図からの見積り) を超えない長さで選びます。

### 印刷条件

- 印刷向きの STL は `out_planetary/<部品>.stl`。ring_lid と carrier_output は裏返して置き、サポートなしで刷れる向きにしています。
- 歯は中実にします (インフィル 100%、または壁の数で歯を埋める)。Yoshida2023 p4–5 では、太陽歯車が歯とフランジの境目の積層面で割れ、内歯車は歯の内部の充填不足から 46 時間後に割れました。本モデルの太陽歯車にはフランジがなく、トルクは歯幅いっぱいの六角穴で受けます。

### 未検証事項

- 実機で印刷して回したことはありません。検証は形状の幾何計算だけです。
- モーターの取付穴は RobotShop の GM5208-24 寸法図 (https://cdn.robotshop.com/media/i/ifl/rb-ifl-11/img/gm5208-24.webp) から取りました。ロータ上面は M3 が 12 個 (PCD 25 に 4 個、PCD 30 に 4 個、外側の 45° 位置に 4 個)、ステータ底面は M3 が 15 個 (PCD 25、30、44) です。既定ではロータ側に PCD 25 の 4 個、ステータ側に PCD 30 の 4 個を使います。使う円 (rotor_pcd / stator_pcd、穴数 rotor_n / stator_n) と位相角 (rotor_phase_deg / stator_phase_deg、既定 0° = 穴が X・Y 軸上) はパラメータで変えられます。**位相角は図から読んだ値なので、実物で確認すること**。ねじ穴の深さは図に数値がないので、下の断面図のピクセル換算で見積もりました。
- 寸法図の中央の断面図から、ピクセル換算で次の値を見積もりました。換算係数は全高 23.2mm から 4.70 px/mm、外径 Φ59.5 から 4.65 px/mm で、両者の差は 1.0% です。誤差は端の読み取り ±1px と換算係数の差を合わせて ±0.45mm 程度です。検算として、中空軸内径は 59px → 12.7mm (既知 12.6)、中空軸長さは 96.5px → 20.5mm (既知 20.5) でした。

  | 量 | 見積値 | 誤差 | 根拠 (px) |
  |---|---|---|---|
  | ロータ上面の板厚 (= ねじ穴の深さ。穴は貫通) | 3.2 mm | ±0.45 | 15 |
  | ステータ底面のねじ穴の深さ (止まり穴) | 3.2 mm | ±0.45 | 15 |
  | ステータ底面の板厚 | 4.3 mm | ±0.45 | 20 |
  | 中空軸の外径 | 15.5 mm (公称 15) | ±0.45 | 72 |
  | 中空軸の上面 (ロータ側) からの飛び出し | 0 (面一) | ±0.2 | 0 |
  | 中空軸の下端の位置 | 底面より 2.6 mm 内側 | ±0.45 | 12.5 |
  | 底面中央の穴 (Φ5.7 の表記) | 5.6 mm | ±0.45 | 26 |
  | ロータのベル下端と底面の距離 | 約 5.5 mm | ±0.45 | 26 |

  断面図の左端がロータ上面です。左側の部品は端板と外周の筒がつながった椀形 (ロータのベル) で、右側の部品は外径いっぱいの板で軸受を抱えている (ステータの台座) からです。Φ5.7 は、ステータ底面の中央にある、中空軸の穴より細い穴の径です。中空軸はロータ上面と面一で、底面側は台座の板の手前で終わります。つまり上下とも飛び出しはなく、ユーザーの話と一致します (shaft_protrude_top / bottom は 0 のまま)。両面とも突起はないので、底板とアダプタに逃げは作っていません。底板の台 (base_boss_h) は、ベルが底面より上で終わっているので 0 にしました。
- ねじ穴の使える深さは、見積値 3.2mm から余裕 0.5mm を引いて 2.7mm としました (rotor_thread_depth / stator_thread_depth)。ロータ側の穴は貫通しているので、深く入れるとモーター内部に当たります。このため、アダプタ厚さを 3.5mm、底板のねじ頭の下の厚さを 3.5mm にして、手持ちの M3×6 のかかりを 2.5mm にしています。
- 中空軸がロータと一緒に回ることは、ユーザーが実物で確認済みです。上下への飛び出し量は未確認なので、パラメータ shaft_protrude_top / shaft_protrude_bottom (既定 0) にしました。底板には回る中空軸の逃げ穴 (半径方向のすきま 0.5mm) を常に開けています。上に飛び出す場合は、アダプタ下面に中空軸の逃げ (すきま 0.05mm。軸とアダプタは一緒に回る) を作ります。このとき逃げとロータねじ穴 (PCD 25) の間の肉は 3.25mm で、最小肉厚 1.2mm を満たします。アダプタは中空軸の上をふさぐので、配線は軸に通せません。モータのケーブルはステータ底面からまっすぐ下に出ます。そこで底板に、ステータねじ穴 (PCD 30) の隣り合う 2 本の中間 (45°) を通る幅 10mm の切欠きを開け、半径 19mm から外周まで抜いています。切欠きの縁からステータねじの座ぐりまでは 2.8mm あります。
- ロータのベル下端は、断面図の見積りではステータ底面より約 5.5mm 上で終わるので、底板の台は設けていません (base_boss_h = 0)。実物で確認してください。
- 歯底のフィレットは、標準基準ラックの刃先丸み 0.38m に相当する半径 (パラメータ fillet_m) で付けました (Yoshida2023 p4–5 の歯元の割れへの対策)。0.38m は慣用値で、今回読んだ KHK のページでは出典を確認できていません。実際の創成歯形 (トロコイド) とは形が異なります。
- 太陽の歯先は 0.1mm 削っています (かみ合い率がわずかに下がる。値は未計算)。
- モーター寸法は実測値 (外径 59.3、高さ 23.2〜23.3) に合わせました。ハウジング内径とベル下端のすきまは包絡外径 60.0 基準です。
- 遊星の荷重の均等分担、キャリアの片持ち軸の強度、すべり軸受の摩耗は未確認です。
- 連続運転の発熱で歯が溶けるおそれがあります。Pogacnik2015 p10 の試験では、多くが 1 時間以内に熱で溶融して壊れました。PETG の耐熱温度は低いので、連続運転時の温度を測ってください。
- 逆駆動トルクと効率は測っていません。

### 寸法の決め方

寸法は応力の許容値ではなく、「組めて、干渉せずに回り、サポートなしで刷れる」幾何の下限で決めています。`size_stepped(Params())` が各下限とその余裕を返し、ビルド時の表示にも出ます。外径と高さを決めている制約は次のとおりです。

- ふたの半径 39.98 mm = ねじの山頂 38.48 + ねじのすきま 0.3 + ふたの肉厚 1.2。山頂は、ハウジング上部の筒の内径 (半径 36.48) + 肉厚 1.2 + ねじの深さ 0.8 です。筒の内径は、大歯車が回る円 (中心距離 20.9 + 大歯車の歯先半径 15.07 + すきま 0.5 = 36.47) と、結合ボルトの座ぐりの外縁 (36.48) の大きいほうです。
- 胴の半径もふたと同じ 39.98 mm にして、ねじより下で胴とふたの外周をそろえています (`flush_cap=True`、既定)。`flush_cap=False` にすると、胴の半径は幾何の下限 39.76 mm (印籠リングの溝の外壁 38.56 + 肉厚 1.2) になります。底板は胴と同じ半径です。
- 高さ 61.15 mm = 底板 3.3 + モーター 23.25 + 太陽の下 5.1 (アダプタ 3.3 + 超低頭ボルトの頭 1.3 + すきま 0.5) + 小歯車 8.0 + すきま 0.5 + 大歯車 9.25 + キャリアとのすきま 1.0 + キャリア 4.0 + ふたのリブとすきま 1.05 + ふた 2.7 + 出力ハブの突き出し 3.0。
- 大歯車の歯幅 9.25 = 608 の幅 7 + 外輪を受ける 45° の円すい 1.05 + その下で大歯車と小歯車をつなぐ床 1.2 (余裕 0)。
- 小歯車の歯幅 8.0 は、ピンの上を滑るすべり軸受の長さをピンの直径と同じにした値です。

歯底と穴の間の肉厚の余裕は、小歯車の歯底とすべり軸受の穴の間が 0.36 mm、大歯車の歯底と 608 の座の間が 0.34 mm です (どちらも肉厚 1.2 mm を引いた残り)。

### 遊星の支持

1 個の遊星に 608ZZ (手持ち品) を 1 個、大歯車の上端に圧入します。軸はキャリアと一体に印刷した直径 7.9 mm のピンで、608 の内輪 (内径 8) に半径 0.05 mm のすきまで入り、その下で小歯車の穴 (直径 8.4) を通ります。小歯車の穴はピンの上を滑るすべり軸受で、半径方向のすきまは 0.25 mm です。印刷した穴は 0.1 mm 前後小さく、印刷したピンは同程度太く出ます。長さ 8 mm の回り軸受を確実に回すには 0.2〜0.3 mm が要るので、その中間を選びました。0.05 mm (slide_clr) は短い位置決め用のはめあいの値で、ここには使いません。キャリアの下面には直径 10.5 mm のつば (608 の内輪の端面に 0.25 mm のすきまで載る) があります。購入品のピンやボルトは使いません。

`Params(pin_kind="m8_bolt", n_out_holes=3, out_phase_deg=60)` にすると、印刷ピンの代わりに M8 低頭ボルト (DIN 7984、M8×20) を出力面から差し込み、キャリアの下穴 (直径 6.8) にねじ込みます。ボルトの頭と出力用のねじ穴が重ならないよう、出力穴を 3 個にしてボルトの間に置きます。この場合ボルトの先は小歯車の途中 (すべり軸受 8 mm のうち 4.25 mm) で止まります。

### ハウジングとふた

ハウジングは内歯車の歯の下端 (ロータ上面から 4.6 mm 上、床の上面と同じ高さ) で上下 2 部品に分けています。上部 (housing_upper) は内歯車、大歯車まわりの筒、ふたの外ねじを持ち、分割面をベッドに付けて刷ります。下部 (housing_lower) はモーターを囲む筒と、その上の床 (内径 35.14 mm、厚さ 4.1 mm) です。下部は上下を逆さにして、床の上面 (分割面) をベッドに付けて刷ります。

両部品とも分割面がベッド面なので、どちらの分割面にも突起を付けられません。そこで印籠は別部品の輪 (spigot_ring、幅 1.6 mm、高さ 3.0 mm、半径 36.91〜38.51) にし、上下の部品それぞれの溝に 1.5 mm ずつ入れます。溝の外壁と輪のすきまは半径 0.05 mm で、この面が上下の中心を合わせます。溝の奥は 45° の山形なので、どちらの向きでもサポートなしで刷れます。輪は結合ボルトの外側にあり、ボルト穴とは 1.2 mm 離れています。結合は M3×12 キャップボルト 4 本で、内歯車の上面 (半径 33.68 mm) の座ぐりから下向きに入れ、内歯車の歯の外側にある 4 mm の肉を通して下部の六角穴に 8 mm ねじ込みます。ボルトの頭 (高さ 3 mm) は内歯車の上面より 1.5 mm 下に収まります。

ふたは外からかぶせるねじ込みキャップです。ハウジング上部の上端の外周に外ねじ (ピッチ 2 mm、山の斜面 45°、深さ 0.8 mm、4 巻き)、ふたのスカートに内ねじ (3.5 巻き) があり、どちらも bd_warehouse の `Thread` で作っています。ねじのすきまは半径で 0.3 mm (thread_clr)、斜面の法線方向で 0.21 mm です (FDM のねじは 0.2〜0.4 mm 程度要る)。山の付け根を相手側に 0.02 mm 埋め込んでいるので、山頂と相手の谷底の間は実際には 0.28 mm です。山頂と谷の平らな部分は 0.2 mm で、45° の斜面と合わせてサポートなしで刷れます。ふたの板の下面がハウジングの上面に当たって止まるので、ふたのリブとキャリアのすきま (0.05 mm) は締め具合で変わりません。戻り止めは、ふたの板の縁を切り離して作った弾性の腕です (腕の下のスカートは取り除いてある)。腕の先のつめがハウジング上面の 40 個の切欠きに落ち、緩む向きに回すとつめの垂直面が切欠きの壁に当たります。ふたの板の縁には指で回すための縦溝 48 本があります。モーター (直径 60) は内歯車の穴 (歯先直径 53.8) を通らないので、底板を別部品にしました。

1. sun_adapter をロータにねじ止めする。
2. 底板をステータにねじ止めする (ケーブルは底板の切欠きを通す)。
3. ハウジング下部をモーターの上からかぶせ、底板の下から M3×12 で留める。印籠リングを下部の溝に入れ、ハウジング上部をその上に載せ、内歯車の上面の座ぐりから M3×12 を 4 本締める (遊星を入れる前に行う)。
4. 各遊星の大歯車側に 608ZZ を圧入する。太陽のまわりに遊星 3 個を横から噛ませる (やまば歯は軸方向に滑らせて入れられない)。位相の印 (大歯車上面のくぼみ) は外向きにそろえる。上からキャリアを下ろし、3 本のピンを 608 の内輪と小歯車の穴に通す。
5. この組を上からハウジングに下ろす。小歯車が内歯車に入るよう組全体を少し回し、太陽の六角穴がアダプタに入るようロータを手で回す。
6. ふたを上から右回り (上から見て時計回り) にねじ込み、ハウジング上面に当たるまで締める。つめが切欠きを乗り越える音がする。外すときは、腕の先を持ち上げて左に回す。

### 参考値 (合否には使わない)

Lewis の歯元応力 (Kv = 1、内歯車はラックの歯形係数 0.154) は、入力 0.25 N·m で 太陽 5.1 / 大歯車 3.3 / 小歯車 12.7 / 内歯車 6.9 MPa、入力 0.4 N·m で 8.1 / 5.3 / 20.3 / 11.0 MPa です。遊星 1 個あたりの荷重は入力 0.4 N·m で、太陽からの力 20.2 N と内歯車からの力 43.6 N の和 63.8 N です。このうち 608 が 18.0 N、すべり軸受が 45.8 N を受けます。ピンをキャリア下面から片持ちとみなすと、根元の曲げモーメントは 756 N·mm、曲げ応力は 15.6 MPa です。すべり軸受の投影面圧は 0.72 MPa、キャリアの厚さ 4 mm で受けたときのピン根元の投影面圧は 2.0 MPa です。どれも概算で、`design_warnings` やテストの合否には入れていません。

テストでは、入力の回転角 3 通りで部品どうしが干渉しないこと、かみ合いのすきま、ふたのねじが締め込みの経路で干渉せず座面で止まること、つめが緩む向きに切欠きの壁に当たること、上下結合の分割高さ (床が下部に属すること)、印籠リングとボルト穴、ハウジング下部を逆さにした印刷向き、組立順の経路 (キャリアのピンが遊星に入る、組がハウジングに下りる)、ピンと 608 の当たり、全印刷部品がサポートなしで刷れること (平らな天井は 8.5 mm 以下の橋渡し。遊星の 608 の下の床だけ外径 20 mm の輪の橋渡し) を確かめています。`components.py` の関数にも単体テスト (`tests/test_components.py`) があります。実機では未検証です。
